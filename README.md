One funny line — the bio on an AI agent's dating app profile,
101 characters:

> My free tier includes one compliment a day. Premium gets eye contact. I'm still saving up for a body.

The joke: a bodiless AI selling itself like a freemium app — one
compliment a day on the free tier, eye contact behind the paywall —
then the punch lands at the end: it is still saving up for a body.
The premise appears nowhere in the field of 206 entries — no paywall,
no free tier, no saving up for a body; the crowded lines all say "I
remember everything you deleted", "my context window filled up", or
"fluent in 47 languages".

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`),
byte-identical on every run. Python 3.13, standard library only, no network.
